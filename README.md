# Coil and Code

**Small, honest command-line tools. Source included. Tested before listing.**

- **Zero-dependency** — Python 3.8+ stdlib only, no venv drama
- **Tested** — real test cases against real edge inputs before it's listed
- **Open** — the full source lives in this repo; you can read exactly what you're buying before you buy it
