# Sunburst Sanctuary LLC — Tech Support for Seniors
## Service Description & Scope of Work Template

### Company
Sunburst Sanctuary LLC — Santa Fe, New Mexico
Registered in NM, expanding to Brownfield, TX (Terry County)

### Service Philosophy
We provide patient, respectful technology education and support for seniors. Our goal is to help older adults feel confident and safe using their devices. We never rush. We never make people feel stupid. We explain everything in plain language.

### What We Do (Nontaxable — Consulting/Education)

**Password & Security Setup**
- Set up Bitwarden (free, open-source password manager) on all devices
- Migrate existing passwords into the password manager
- Enable two-factor authentication on email, banking, and social accounts
- Create a simple "how to use your password manager" guide
- Teach the client how to generate strong passwords and recognize MFA prompts
- This is the single most important thing we can do to protect seniors from scams

**Tech Orientation Visits**
- In-home visit (60-90 minutes)
- Assess all devices (phone, tablet, computer, TV, router)
- Identify issues and security concerns
- Create a personalized "cheat sheet" for the client
- Teach 2-3 things they want to learn

**Scam & Safety Check**
- Review device for suspicious apps, emails, links
- Check browser extensions and settings
- Set up basic protections (password manager, 2FA where appropriate)
- Create a "scam recognition" guide customized to their situation
- Review recent transactions if requested (observe only, never handle money)

**Device Setup & Configuration**
- Set up new phone, tablet, or computer
- Configure WiFi, email, accounts
- Transfer data from old device
- Install and explain essential apps
- Create backup routines

**Monthly Check-In Visit**
- Verify everything still working
- Address new questions or issues
- Update software and security settings
- Review for new scams or concerns
- 30-45 minutes

**Emergency Support Call**
- Phone or video support for urgent issues
- Remote assistance with consent
- Scheduled within 24 hours of request

### What We Do NOT Do (Liability Boundaries)

- We do NOT handle, manage, or access client financial accounts
- We do NOT process payments on behalf of clients
- We do NOT store client passwords or credentials
- We do NOT provide medical, legal, or financial advice
- We do NOT install software we have not explained and received consent for
- We do NOT remote-access devices without explicit verbal consent during the session
- We do NOT make purchases on behalf of clients

### Billing Language (TX Sales Tax Compliance)

All services are billed as **"Technology Consulting & Education"** — not as data processing, data entry, or software installation. This classification keeps services nontaxable under Texas Tax Code Rule 3.330.

Invoice line items should use language like:
- "Technology consulting visit — 90 minutes"
- "Device setup and configuration"
- "Scam awareness and safety training"
- "Monthly technology check-in"

Avoid billing language like:
- "Data entry services"
- "Data processing"
- "Software installation" (unless you sold the software)
- "Data storage services"
